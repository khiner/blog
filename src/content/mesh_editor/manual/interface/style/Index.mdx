**Panels → Style** changes the appearance of the editors. **Reset** restores the defaults for the current tab.

## Viewport

| Setting | Effect |
| --- | --- |
| **Background** | Background color of the viewport. |
| **Grid** | Color and opacity of the ground grid. |
| **Axis Colors → X** | Color used to identify the X axis. |
| **Axis Colors → Y** | Color used to identify the Y axis. |
| **Axis Colors → Z** | Color used to identify the Z axis. |
| **Wire** | Wire color in Object mode. |
| **Wire Edit** | Wire color in mesh Edit mode. |
| **Object Active** | Outline color of the active object. |
| **Object Selected** | Outline color of other selected objects. |
| **Light** | Color of light object guides. |
| **Vertex** | Color of unselected mesh vertices. |
| **Vertex Selected** | Color of selected vertices. |
| **Edge Selected Incidental** | Color of an edge highlighted through selection of neighboring elements. |
| **Edge Selected** | Color of directly selected edges. |
| **Edge Sharp** | Color of edges marked sharp. |
| **Face Selected Incidental** | Color of a face highlighted through selection of its elements. |
| **Face Selected** | Color and opacity of directly selected faces. |
| **Element Active** | Highlight on the active mesh element. |
| **Element Excited** | Highlight on the mesh element being struck in Excite mode. |
| **Face Normal** | Color of normal lines drawn at face centers. |
| **Vertex Normal** | Color of normal lines drawn at vertices. |
| **Bone Solid** | Body color of armature bones. |
| **Bone Pose** | Highlight color of selected pose bones. |
| **Bone Pose Active** | Highlight color of the active pose bone. |
| **Transform** | Color of transform guides. |
| **Edge Width** | Width in pixels of mesh edges, wireframes and line overlays. |
| **Silhouette Edge Width** | Width in pixels of the outline around selected objects. |

## Nodes

### Colors

| Setting | Effect |
| --- | --- |
| **Background** | Node canvas background. |
| **Grid** | Fine grid lines. |
| **Coarse Grid** | Major grid lines. |
| **Node** | Fill of the node body. |
| **Tray** | Fill behind the parameter sockets. |
| **Title** | Text in the node title bar. |
| **Label** | Text beside ordinary sockets. |
| **Parameter Label** | Text beside parameter sockets. |
| **Border** | Border around an ordinary node. |
| **Selected** | Border around a selected node. |
| **Active** | Border around the active node. |
| **Error** | Border of a node with an evaluation error. |
| **Warning** | Border of a node with a warning. |
| **Outline** | Outline of sockets, trays and chevrons. |
| **Hovered** | Highlight of the socket or control under the pointer. |
| **Wire Highlight** | Highlight of a wire during interaction. |
| **Box Select** | Fill of the selection rectangle. |
| **Box Select Border** | Outline of the selection rectangle. |
| **Dimmed** | Color of an incompatible socket while dragging a wire. |
| **Dimmed Label** | Text color for an incompatible socket. |
| **Chevron** | Arrow on a parameter tray with no linked parameters. |
| **Chevron Linked** | Arrow on a tray with linked parameters. |

The title bar and socket colors are also individually editable.

| Setting | Effect |
| --- | --- |
| **Sources Title** | Title bar of source nodes. |
| **Operators Title** | Title bar of mesh operation nodes. |
| **Combine Title** | Title bar of geometry combination nodes. |
| **Attributes Title** | Title bar of attribute nodes. |
| **Math Title** | Title bar of math nodes. |
| **Generators Title** | Title bar of generator nodes. |
| **Instances Title** | Title bar of instancing nodes. |
| **Displayed Title** | Title bar of the node whose result is displayed in the viewport. |

| Setting | Effect |
| --- | --- |
| **Geometry Socket** | Color of geometry sockets. |
| **Instances Socket** | Color of instance sockets. |
| **Image Socket** | Color of image sockets. |
| **Float Socket** | Color of floating-point sockets. |
| **Integer Socket** | Color of integer sockets. |
| **Boolean Socket** | Color of Boolean sockets. |
| **Vector Socket** | Color of vector sockets. |
| **Vector4 Socket** | Color of four-component vector sockets. |
| **Color Socket** | Color of color sockets. |
| **Matrix Socket** | Color of matrix sockets. |
| **Mixed Socket** | Color of mixed-type sockets. |

### Sizes

| Setting | Effect |
| --- | --- |
| **Frame height** | Uses the height of one interface control as the side length of a grid cell. |
| **Grid size** | Grid cell side length in points when **Frame height** is off. |
| **Coarse Grid Cells** | Number of cells between major grid lines. |
| **Max Label Cells** | Maximum socket label width in grid cells. Longer labels end in an ellipsis. |
| **Title Padding** | Space on each side of the node title. |
| **Label Spacing** | Space between a socket and its label. |
| **Parameter Indent** | Additional indentation for parameter labels. |
| **Socket Radius** | Radius of a socket. |
| **Rounding** | Corner radius of a node. |
| **Margin** | Space between a node and the edges of its grid cells. |
| **Wire Width** | Thickness of a connection. |
| **Wire Curving** | Curvature of a wire as it leaves a socket, relative to the horizontal span of the connection. |
| **Border Width** | Thickness of an ordinary node border. |
| **Highlight Border Width** | Thickness of the border on a selected, active or failing node. |
| **Outline Width** | Outline thickness on sockets, trays and chevrons. |

## Timeline

| Setting | Effect |
| --- | --- |
| **Background** | Timeline background outside the playback range. |
| **Frame Range** | Background within the playback range. |
| **Ruler Line** | Line separating the frame ruler from the keyframes. |
| **Major Tick** | Color of the labeled ruler ticks. |
| **Minor Tick** | Color of the unlabeled ruler ticks. |
| **Tick Label** | Color of frame numbers on the ruler. |
| **Keyframe** | Fill of a keyframe marker. |
| **Keyframe Outline** | Outline of a keyframe marker. |
| **Playhead** | Color of the line marking the current frame. |
| **Playhead Label** | Text color of the current frame number. |
| **Playhead Label Background** | Fill behind the current frame number. |
| **Ruler Height** | Height of the frame ruler in points. |
| **Tick Label Spacing** | Minimum space between labeled ticks. |
| **Minor Tick Spacing** | Minimum distance between labeled ticks before intermediate ticks appear. |
| **Keyframe Radius** | Radius of each keyframe marker. |
| **Keyframe Padding** | Space between the ruler and the keyframe markers. |
| **Playhead Width** | Width of the current-frame line. |
| **Playhead Label Rounding** | Corner radius of the current-frame label. |
| **Playhead Label Padding** | Horizontal and vertical space around the frame number. |

## Interface

| Setting | Effect |
| --- | --- |
| **Tool Button Size** | Width and height of the viewport tool buttons. |
| **Header Button Size** | Width and height of the buttons in the viewport header. |
| **Icon Button Rounding** | Corner radius of icon button groups. |
