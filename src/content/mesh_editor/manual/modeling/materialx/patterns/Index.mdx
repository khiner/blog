Use UV coordinates for a pattern that follows an unwrapped surface. For a pattern that runs through the object, connect object-local **Position** to a 3D noise node.

## Procedural

### Constant

Use a fixed value of the selected type.

<OperationPorts
  identifier="constant"
  inputs={{

    ["boolean, integer, float, vector2, vector3, vector4, color3, color4, matrix33, matrix44", {"sameAs": "Value"}],
