## Texture 2D

Reduce visible tiling by blending randomized, hexagonal image samples.

<OperationPorts

## Convolution 2D

### Blur

Soften detail in an image or a field that uses one UV coordinate set. For a field that reads mesh geometry or combines several UV sets, [bake the field to an image](/MeshEditor/manual/modeling/fields/#image-baking) first. A nonzero blur of an image or varying field has a preview in **Properties → Image**.

<OperationPorts
  identifier="blur"
  inputs={{
    "In": "The image or sampled field to blur.",
    "Size": "Width of the neighborhood in UV units. Zero passes the input through. The largest supported width is 32.",
  }}
  properties={{
    "Filtertype": "Box weights all samples equally. Gaussian gives nearby samples more weight.",
  }}
  result="A smoothed image or field. Wider neighborhoods soften broader features."
  fixedTypes={{
    "Size": "float",
  }}
  columns={["In", "Output"]}
  rows={[
    ["float, vector2, vector3, vector4, color3, color4, image", {"sameAs": "In"}],
  ]}
/>

## NPR

### Facing Ratio

Measure how directly a surface faces the viewer. Supply the view direction and normal in the same coordinate space.

<OperationPorts
  identifier="facingratio"
  inputs={{
    "Viewdirection": "Unit direction from the viewer to the surface.",
    "Normal": "Unit surface normal.",
    "Faceforward": "Treat both sides as front-facing. Turn off for negative values on back faces.",
    "Invert": "Subtracts the facing value from 1.",
  }}
  result="Before inversion, 1 on a directly front-facing surface and 0 at a grazing angle."
  fixedTypes={{
    "Viewdirection, Normal": "vector3",
    "Faceforward, Invert": "boolean",
    "Output": "float",
  }}
/>
