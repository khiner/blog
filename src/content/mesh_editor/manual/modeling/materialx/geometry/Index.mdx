## Geometric

### Adjacent

Grow or shrink a selection by successive rings of neighbors.

<OperationPorts
  identifier="adjacent"
  inputs={{
    "In": "The selection to grow or shrink.",
    "Steps": "The number of rings to add or remove.",
  }}
  properties={{
    "Domain": "Select vertices, edges or faces.",
    "Mode": "Choose more to add neighbors or less to remove boundary elements.",
  }}
  result="A selection expanded or contracted by the chosen number of rings."
  fixedTypes={{
    "In": "boolean",
    "Steps": "integer",
    "Output": "boolean",
  }}
  contexts="vertices, edges, faces, face corners"
/>

### Bump

Tilt a surface normal according to changes in height.

<OperationPorts
  identifier="bump"
  inputs={{
    "Height": "The surface height field. Changes between neighboring samples create the relief.",
    "Scale": "The strength of the bump effect.",
    "Normal": "Surface normal before perturbation.",
    "Tangent": "The surface tangent along the first texture axis.",
    "Bitangent": "The surface direction along the second texture axis.",
  }}
  result="A normal tilted by the local height variation."
  fixedTypes={{
    "Height, Scale": "float",
    "Normal, Tangent, Bitangent": "vector3",
    "Output": "vector3",
  }}

/>

### Convert Domain

Transfer a field between mesh element domains.

<OperationPorts
  identifier="convertdomain"
  inputs={{
    "In": "The field to read on the source elements.",
  }}
  properties={{
    "Source Domain": "The vertex, edge, face or face-corner domain that holds the original values.",
    "Target Domain": "Element domain that receives the result.",
    "Mode": "For a selection, Any includes a target when any source element is selected. All requires every source element. Numeric fields offer mean, minimum or maximum.",
  }}
  result="One value per target element. A target with no related source elements receives zero."
  columns={["In", "Output"]}
  rows={[
    ["boolean, integer, float, vector2, vector3, vector4, color3, color4", {"sameAs": "In"}],
  ]}
  contexts="vertices, edges, faces, face corners"
>

Set **Source Domain** to face and **Target Domain** to edge. An edge shared by a selected and an unselected face is selected with **Any** and unselected with **All**.

</OperationPorts>

### Element Index

Read the index on the chosen element domain. Indices can change when topology changes.

<OperationPorts
  identifier="elementindex"
  result="The zero-based index of the current element in its domain."
  fixedTypes={{
    "Output": "integer",
  }}
  contexts="vertices, edges, faces, face corners"
>

A vertex keeps the same index until an edit renumbers it. A field based on that index changes when its index changes.

</OperationPorts>

### Geometry Color

Read the mesh’s color. Faces can have different colors on either side of a shared edge. Meshes made entirely of points or edges use vertex colors.

<OperationPorts
  identifier="geomcolor"
  inputs={{
    "Index": "Use 0 for the mesh color set. Other indices return zero.",
  }}
  result="The color at the current point. A float output reads its red channel."
  fixedTypes={{
    "Index": "integer",
  }}
  columns={["Output"]}
  rows={[
    ["float, color3, color4"],
  ]}
  contexts="face corners, vertices on meshes without faces, UV bakes"
/>
