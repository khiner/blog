Deformation nodes move vertices in the input mesh. **Selection** accepts a `Boolean` field or a stored selection. Where available, **Frame Position**, **Frame Rotation** and **Frame Scale** place the mesh in the coordinate system for the edit.

**Output** · Every node on this page produces the deformed **Geometry**.

<h3 id="smoothvertices">Smooth Vertices</h3>

Smooths the selection by moving each vertex toward the average position of its neighbors.

| Input | Type | Description |
| --- | --- | --- |
| **Geometry** | `Geometry` | Mesh supplied to this operation. |
| **Selection** | `Boolean` field | Vertices to smooth. |
| **Factor** | `Float` field | Fraction of the distance toward the neighbor average to move on each pass. |
| **Repeat** | `Integer` | Number of smoothing passes. |
| **X** | `Boolean` | Allows the operation to change the X coordinate. Disable it to preserve that coordinate. |
| **Y** | `Boolean` | Allows the operation to change the Y coordinate. Disable it to preserve that coordinate. |
| **Z** | `Boolean` | Allows the operation to change the Z coordinate. Disable it to preserve that coordinate. |

<h3 id="shrinkfatten">Shrink Fatten</h3>

Moves vertices along their normals.

| Input | Type | Description |
| --- | --- | --- |
| **Geometry** | `Geometry` | Mesh supplied to this operation. |
| **Selection** | `Boolean` field | Vertices to displace along their normals. |
| **Distance** | `Float` field | Signed displacement along the normal. Positive values expand an outward-facing surface and negative values shrink it. |
| **Even** | `Boolean` | Compensates for the angle between adjacent faces to maintain thickness at corners. |

<h3 id="randomize">Randomize</h3>

Displaces selected vertices in a repeatable random pattern.

| Input | Type | Description |
| --- | --- | --- |
| **Geometry** | `Geometry` | Mesh supplied to this operation. |
| **Selection** | `Boolean` field | Vertices to displace. |
| **Amount** | `Float` field | Maximum displacement in mesh-local units. |
| **Uniform** | `Float` | Controls variation in distance. At 0 the distance varies between vertices. At 1 every vertex moves the full amount. |
| **Normal** | `Float` | Controls alignment with the vertex normal. At 0 directions are random. At 1 displacement is along the normal in either direction. |
| **Seed** | `Integer` | Integer that selects the random pattern. |

<h3 id="spaceevenly">Space Evenly</h3>

Redistributes vertices at equal intervals along a path.

| Input | Type | Description |
| --- | --- | --- |
| **Geometry** | `Geometry` | Mesh supplied to this operation. |
| **Selection** | `Boolean` field | Path of vertices to redistribute. |
| **Factor** | `Float` | Fraction of the correction from the original positions to evenly spaced positions. |
| **X** | `Boolean` | Allows the operation to change the X coordinate. Disable it to preserve that coordinate. |
| **Y** | `Boolean` | Allows the operation to change the Y coordinate. Disable it to preserve that coordinate. |
| **Z** | `Boolean` | Allows the operation to change the Z coordinate. Disable it to preserve that coordinate. |

| Property | Description |
| --- | --- |
| **Interpolation** | **Linear** follows straight segments between vertices. **Cubic** follows a smooth curve through them. |

<h3 id="relaxedgeloops">Relax Edge Loops</h3>

Smooths the shape of an edge loop.

| Input | Type | Description |

| **Selection** | `Boolean` field | Edge loops to smooth. |
| **Iterations** | `Integer` | Number of smoothing passes. |
| **Even Spacing** | `Boolean` | Redistributes vertices at equal intervals along the smoothed curve. |

| Property | Description |
| --- | --- |
| **Interpolation** | **Linear** follows straight segments between vertices. **Cubic** follows a smooth curve through them. |

<h3 id="curvebetweenselected">Curve Between Selected</h3>

Fits the vertices of a path to a curve through the selected anchor vertices.

| Input | Type | Description |
| --- | --- | --- |
| **Geometry** | `Geometry` | Mesh supplied to this operation. |
| **Selection** | `Boolean` field | Anchor vertices through which the curve passes. |
| **Factor** | `Float` | Fraction of the displacement from the original positions to the fitted curve. |
| **Extend** | `Boolean` | Continues the fit beyond the outer selected anchors. |
| **Regular** | `Boolean` | Spaces the vertices evenly along the curve. |
| **X** | `Boolean` | Allows the operation to change the X coordinate. Disable it to preserve that coordinate. |
| **Y** | `Boolean` | Allows the operation to change the Y coordinate. Disable it to preserve that coordinate. |
| **Z** | `Boolean` | Allows the operation to change the Z coordinate. Disable it to preserve that coordinate. |

| Property | Description |
| --- | --- |
| **Interpolation** | **Linear** follows straight segments between vertices. **Cubic** follows a smooth curve through them. |
| **Elevation** | Restricts motion along the surface normal. **Raise** allows outward motion, **Lower** allows inward motion and **None** allows either direction. |

<h3 id="circularize">Circularize</h3>

Fits an edge loop to a circle. The viewport command is **To Circle**.

| Input | Type | Description |
| --- | --- | --- |
| **Geometry** | `Geometry` | Mesh supplied to this operation. |
| **Selection** | `Boolean` field | Loop to fit to a circle. |
| **Factor** | `Float` | Fraction of the displacement toward the circle. |
| **Radius** | `Float` | Radius of the circle. Zero uses the fitted radius. |
| **Angle** | `Float` | Rotates the vertices around the center of the fitted circle. |
| **Regular** | `Boolean` | Spaces vertices at equal angles. When disabled, each vertex keeps its original angular position. |
| **X** | `Boolean` | Allows the operation to change the X coordinate. Disable it to preserve that coordinate. |
| **Y** | `Boolean` | Allows the operation to change the Y coordinate. Disable it to preserve that coordinate. |
| **Z** | `Boolean` | Allows the operation to change the Z coordinate. Disable it to preserve that coordinate. |

| Property | Description |
| --- | --- |
| **Method** | **Least Squares** fits the circle to the loop vertices. **Contract** takes the radius from the vertex closest to the fitted center. |

<h3 id="flatten">Flatten</h3>

Projects each selected region onto a plane.

| Input | Type | Description |
| --- | --- | --- |
| **Geometry** | `Geometry` | Mesh supplied to this operation. |
| **Selection** | `Boolean` field | Regions to project onto a plane. |
| **Factor** | `Float` | Fraction of the distance each vertex moves toward the plane. |
| **View Normal** | `Vector` | Direction perpendicular to the plane in **View** mode, expressed in frame coordinates. |
| **X** | `Boolean` | Allows the operation to change the X coordinate. Disable it to preserve that coordinate. |
| **Y** | `Boolean` | Allows the operation to change the Y coordinate. Disable it to preserve that coordinate. |
| **Z** | `Boolean` | Allows the operation to change the Z coordinate. Disable it to preserve that coordinate. |
| **Frame Position** | `Vector` | Translation from mesh-local coordinates into the space used by this operation. |
| **Frame Rotation** | `4D Vector` | Rotation from mesh-local coordinates into the space used by this operation. |
| **Frame Scale** | `Vector` | Scale applied when converting mesh-local positions into the space used by this operation. |

| Property | Description |
| --- | --- |
| **Method** | **Least Squares** fits the plane to the vertices. **Face Normals** orients the plane from the selected faces. **View** uses the **View Normal** input. |

<h3 id="snapsymmetry">Snap Symmetry</h3>

Aligns pairs of vertices across a symmetry plane.

| Input | Type | Description |
| --- | --- | --- |
| **Geometry** | `Geometry` | Mesh supplied to this operation. |
| **Selection** | `Boolean` field | Vertices to align across the symmetry plane. |
| **Threshold** | `Float` | Maximum distance from a reflected position at which two vertices can form a pair. |
| **Factor** | `Float` | At 0 the reference side stays in place. At 1 the opposite side stays in place. At 0.5 both move equally. |
| **Negative** | `Boolean` | Uses the negative side of the axis as the reference. When disabled, uses the positive side. |
| **Center** | `Boolean` | Snaps vertices near the symmetry plane onto the plane. |

| Property | Description |
| --- | --- |
| **Axis** | Axis perpendicular to the symmetry plane, either **X**, **Y** or **Z**. |

<h3 id="setposition">Set Position</h3>

Sets or offsets the coordinates of selected vertices.

| Input | Type | Description |
| --- | --- | --- |
| **Geometry** | `Geometry` | Mesh supplied to this operation. |
| **Position** | `Vector` field | Position or displacement vector evaluated for each selected vertex, in mesh-local coordinates. |
| **Selection** | `Boolean` field | Vertices whose positions can change. Unselected vertices keep their coordinates. |
| **Offset** | `Boolean` | Adds **Position** to each vertex’s coordinates. When disabled, **Position** replaces the coordinates. |

#### Examples

With **Offset** enabled, a constant **Position** of (0, 1, 0) moves every selected vertex one unit along Y. With **Offset** disabled, the same input places all selected vertices at (0, 1, 0).
