Select a node in **Nodes** to edit its settings in **Properties**. An unlinked **Selection** input can use the selection stored on the node. [Node selections](/MeshEditor/manual/modeling/geometry-nodes/#node-selections)

- The **Input** column names sockets you can connect. **Property** tables list settings on the node. A *field* can vary by mesh element or image sample. An *ordered* input takes several links in sequence.
- **Output** names the result you can pass to another node. Generators, topology nodes and deformation nodes all produce **Geometry**. Other nodes can produce points, instances, images or values.
