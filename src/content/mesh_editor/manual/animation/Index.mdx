A clip plays a set of animated properties together. Insert keys at different frames to specify how a property changes over time.

## Animation targets

A clip can animate object transforms and visibility, pose bones, morph weights, camera lenses, lights, image-based lighting, material properties and texture transforms. A material animation affects every object that uses that material. Morph weights can deform a mesh alongside its skin. [Morph targets](/MeshEditor/manual/animation/morph-targets/)

**Targets** in the Timeline's playback options lists the active clip's properties. Switching or leaving a clip restores rest values for properties it stops driving. Interpolation determines the values between keys. [Keyframe interpolation](/MeshEditor/manual/animation/keyframes/#interpolation)

## Playback

Drag in the **Timeline** ruler to scrub. **Up** jumps to the previous key for the selection and **Down** to the next. **Space** plays or pauses. **Esc** during playback returns to the frame where playback began. [Timeline controls](/MeshEditor/manual/editors/timeline/)
