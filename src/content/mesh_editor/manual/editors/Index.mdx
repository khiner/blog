Select and edit objects in the **3D viewport**. **Scene controls** changes the active view, switches scenes and adds objects. **Properties** follows the selected item. Select a camera to edit its lens, or select **Document** in **Nodes** to edit simulation settings.

Use **Nodes** to follow a connection to a mesh, material or armature. Use the **Timeline** to scrub an animation or play a simulation. Open **Info** for help with the control under the pointer. [Panels and fields](/MeshEditor/manual/interface/) · [Node editing](/MeshEditor/manual/interface/nodes/)
